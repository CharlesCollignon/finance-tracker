# `@finance/core`

Pure TypeScript shared by both apps, shipped as source (no build step):
every calculation, every rule, every zod schema, every string. The root
`AGENTS.md` applies too.

## Rules

- **Pure.** No network, no database, no React, no `Date.now()` hidden inside
  a calculation. Take "today" as an argument. Time-zone logic uses
  `APP_TIME_ZONE` (Europe/Paris) from `src/constants.ts`.
- **Tested beside the code.** `foo.ts` has `foo.test.ts`. Run
  `pnpm --filter @finance/core test`. A figure shown to someone is covered by
  a test that states it.
- **Exported on purpose.** A module both apps import is listed in
  `package.json` `exports` (`"./foo": "./src/foo.ts"`) and imported as
  `@finance/core/foo`. knip fails on an export nothing reads. Add an export in
  the same commit as its first reader.
- **Both platforms.** The phone runs this code on Hermes, which is several
  times slower than Node. Heavy loops (the Plan's replay, the year ahead)
  were rewritten for it. To estimate the cost, bundle a script with esbuild
  and run it with `node --jitless`, then multiply by 2–3. To prove a speed-up
  changes no figure, diff the JSON results before and after.

## Strings (`src/i18n/`)

- `messages/fr.ts` and `messages/en.ts` hold every string both apps show.
  French is written first. English is the fallback for a missing key.
- `t()` (`src/i18n/t.ts`) fills `{placeholders}` and elides French « de » /
  « que » before a vowel (« d'octobre »). Don't hand-build French sentences
  around it.
- `src/i18n/unused-keys.test.ts` fails on a key nothing uses. Remove keys
  with the code that used them.
- Words follow `CONTEXT.md`.

## Files with a special role

| File                                  | Role                                                                                                               |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `src/changelog-entries.ts`            | « Nouveautés ». Every visible change adds an entry (root `AGENTS.md`).                                            |
| `src/flags.ts`                        | Feature switch keys. Anything short of a clear "on" is off.                                                        |
| `src/notification-kinds.ts`           | Every push kind. On unless the person turned it off.                                                               |
| `src/designs.ts`, `design-palettes.ts`| The four designs. `design-parity.test.ts` holds the phone's values to the web's CSS.                              |
| `src/types/database.generated.ts`     | Generated by `pnpm gen:types`. Never edit by hand. Narrow types in `types/database.ts`.                            |
| `src/statement/`                      | Statement readers (CSV/XLSX/ODS/OFX/QIF/CAMT/MT940/CFONB/PDF), alerts and notifications.                          |
| `src/history/`                        | The Plan's market history and replay. Data is CC BY-NC: Pluclair must stay free while it is used.                 |
| `src/paging.ts`                       | `allRows`: any query that can pass Supabase's 1,000-row cap goes through it.                                       |
